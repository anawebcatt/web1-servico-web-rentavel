CombinaCor

Escolha uma cor e veja cores que combinam com ela.

Tipo de paleta

Paleta

Cinza, branco e preto não têm matiz, então só a paleta monocromática gera variações dessa cor.

    CSS pronto

    Publicidade
    300 × 250

    Como usar

    1. Escolha a cor base no seletor ou digite o código HEX, como #0047AB.
    2. Escolha o tipo de paleta. As cores mudam na hora.
    3. Copie o código da cor que quiser, ou o bloco de CSS pronto, e cole no seu arquivo CSS.

    Tipos de paleta

    Complementar
    A cor base e a cor do lado oposto do círculo cromático. Dá bastante contraste: boa para destacar um botão ou um link.
    Análoga
    A cor base e as duas vizinhas dela no círculo cromático. As cores são parecidas, e o resultado é suave.
    Tríade
    Três cores com a mesma distância entre si no círculo cromático. Fica colorido e equilibrado.
    Monocromática
    A mesma cor em versões mais escuras e mais claras. Boa para fundos, bordas e textos de um mesmo tema.

    Como usar as cores no CSS

    Cole o bloco de CSS pronto no começo do seu arquivo. Cada cor vira uma variável, que você usa com var(): 

    button {
  background-color: var(--cor-1);
}

    HEX, RGB e HSL são três jeitos de escrever a mesma cor. Qualquer um dos três funciona no CSS.
