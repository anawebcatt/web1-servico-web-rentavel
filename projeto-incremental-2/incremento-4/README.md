## Plano para o CombinaCor

- Usar a [The Color API](https://www.thecolorapi.com/) para mostrar o nome de cada cor da paleta (os nomes vêm em inglês).
- Oferecer também as paletas geradas pela própria API, pelo endpoint `/scheme`.
- Se a API falhar, a paleta continua funcionando com as contas do `cores.js`; só os nomes ficam faltando.
